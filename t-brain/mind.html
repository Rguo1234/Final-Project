Brain

The turtle has a fun little brain inspired by basic machine learning principles and specifically a neural network

What is a neural network?
Neural networks are a set of weights and neurpons that can be tuned to change the machine's behavior normally to minimize some loss function

What type of neural network?
This is a spike neural network (slightly more similar to an actual brain than what are used normally)

This model architecture
15 input neurons, 20 hidden neurons, and 5 output corresponding to the turtle's behavior

The network trains off of this loss function
L(t, y) = (y_target - y)^2 + (t - 1000)

What kind of neurons?
LIF or Leaky Integrate and Fire, which integrate to some threshold before firing a spike and sending that signal to every other neuron
