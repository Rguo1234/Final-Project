Help Guide

Can't buy anything?
Every once in a while a star code will appear in the turtle's house, press Get Pearls in shop then type in your star code to get pearls

Can't see additionally information on personality results?
A code should be given type it in the results page to see full detailed information on your seabody

Star code doesn't work?
You probably have already used that star code

You should be able to buy each item under the amount of pearls you have
If you have 20 pearls you can buy seagrass, urchin, jellyfish, and fish by reloading the page and buying different codes each time

Everything has infinite stock, you can buy as much of an item as you want

General Information about Turtles

Turtles are the most amazing animal. They have 4 legs, a shell, and can live in various different biomes as well as climates.
